Installation

Download zip file NodeEEBench.zip

Windows

Unzip file into C:\temp on a Windows PC creating a subdirectory NodeEEBench.
Change to subdirectory c:\temp\NodeEEBench.

Linux

Unzip file into a directory
Install node.js
Follow instructions and start in a shell: node ServerEEBench.js
instead of the .bat file.

Installation Simulation

  1. Start NodeEEBench.bat by double clicking
    This starts a node program for a webserver: ServerEEBench.js
    A command line window opens monitoring the serial communication between server and web interface. Since no attached Arduino or FPGA is detected Simulation is started.
  2. Open with the browser 'localhost:3000'
    This delivers the file 'Projekte/NEEBench.html' with the user interface
  3. Select the Simulation
    Start the waveform generator
    Start the oscilloscope and look at the waveform

Installation FPGA (BASYS3, CMOD A7, R2R, PMOD AD2, DA2, MCP4728)

  1. Wire and connect BASYS3 FPGA board to your PC (BASYS3)
  2. (Download) Open Vivado 19.1
  3. Open project in folder Xilinx/EEBench/EEBench.xpr.
    Project Manager, Settings, Bitstream activate -bin_file* for bin file creation for Flash memory start up
    Activate constraints for CMOD A7 or BASYS3 (right click).
    Set as top EEBench or EEBenchCA7 (right click).
    Compile and transfer bit file into FPGA or better bin file into Flash memory.
    The Basys 3 Programming Guide can be used to do the Flash programming.
  4. Start NodeEEBench.bat by double clicking
    This starts a node program for a webserver: ServerEEBench.js
    A command line window opens monitoring the serial communication between Arduino and web interface
  5. Open with the browser 'localhost:3000'
    This delivers the file 'Projekte/NEEBench.html' with the user interface
  6. Select the BASYS 3 board
    Start the waveform generator
    Start the oscilloscope and look at the waveform

Installation Arduino MKR WiFi 1010

  1. Wire and connect the Arduino MKR WiFi 1010 board to your PC
  2. Open project in folder Arduino/EEBench/EEBench.ino compile and transfer program
    Library Arduino MKR WiFi 1010 for SAMD boards should be installed. (Tools, Board Manager, SAMD)
    Manage Libraries, "adafruit mcp4728" (Tools, Manage Library, Adafruit)
    Select COM Port and Board. (Tools, Port, COMx (Arduino). Upload Sketch
  3. (Edit NodeEEBench.bat and adjust the path according to your installed node.exe)
  4. Start NodeEEBench.bat by double clicking
    This starts a node program for a webserver: ServerEEBench.js
    A command line window opens monitoring the serial communication between Arduino and web interface



  5. Open with the browser 'localhost:3000'
    This delivers the file 'Projekte/NEEBench.html' with the user interface



  6. Select the Arduino board
    Start the waveform generator AWG1 tab: Frequency 20 Hz, Amplitude 1 V, Offset 1 V, "Run"
    In the command interface the S command will be shown.
    Start the oscilloscope OSC, change Time Base 20 ms/div, "Run" and look at the waveform
    In the command interface the U command and received data are shown
  7. The Configuration window shows additional resources and all available commands
