Oscilloscope input circuit

The Arduino ADCs have an input range from 0V .. 3.3V.
The BASYS3 Artix FPGA supports an input range from 0V to 1 V.
The input range should be from -5 V.. 5V. (-10 V .. + 10 V)

Vout2 = Vinx / (1 + R5/R7+ R5/R6) + V33 /(1 + R6/R7 + R6/R5)
Vout2 = Vinx / (1 + 1 + 1/0.69) + V33 /(1 + 0.69 + 0.69) = 0.29 Vinx + 0.437 V33
Vout2(Vinx=-5V,V33=3.3V) = -0.00853 V
Vout2(Vinx=5V,V33=3.3V) = 2.8906 V
RVinx2 = R5 + R6*R7/(R6+R7) = 1.4 MOhm
Vout3 = Vinx / (1 + 10 + 1/0.69) + V33 /(1 + 6.9 + 0.69) = 0.0803 Vinx + 0.116 V33
Vout3(Vinx=-5V,V33=3.3V) = -0.01746 V
Vout3(Vinx=5V,V33=3.3V) = 0.785 V
RVinx3 = R8 + R9*R10/(R9+R10) = 1.087 MOhm

Websocket communication


The websocket uses the following P command to set voltages.
"P" command sets power supplies MCP4728
P<VA><IA><VB><IB><VC><IC><VD><ID> Each value 16 Bit, 4 Hex numbers = 32 Hex numbers total

Arduino I2C SDA, SCL


Library: (MCP4728,) Adafruit_MCP4728
This uses the default speed of 100kHz: 10us pulse width SCL:
  Wire.setClock(100000);
The Wire module is also used by the PMOD AD2 with the following statement to speed up acquisition to ts = 430us sample time. 700ns pulse width SCL
  Wire.setClock(1600000); // to keep 430us cycle

Output range conversion


A power supply for AWG and DAC, VA = V+, VB = V-, VC = V1, VD = V2 for conversion of 0V..3.3V range to a range of +5V to -5V is needed.
An inverting rail-to-rail amplifer MCP6022 will convert the range.

The resistor values are based on available parts.
V = - 5 V, Vout = 0..3.3V
Vout1 = - R4 (V-/R3 + Vout (1/R1 + 1/R2) ) = - V- + 3.13 Vout
Vout1(Vout = 0 V) = 5 V
Vout1(Vout = 3.3 V) = - 5.3 V
R12=1/(1/R1+1/R2) = 150 kOhm

2 chips are used for 4 output level converters.


Power supply


A VDD = 5 V USB power supply should generate a V- = -5 V voltage.

An 8 pin TC7660 charge pump with a DIL package for the breadboard is used.

Pin 1 open, Pin2 C1+, Pin 3 GND, Pin4 C1-, Pin 5 Vout C2-, Pin & open, Pin 7 open, Pin 8 VDD.
C1, C2 = 10 uF
Rout = 70 Ohm; I = -10mA gives -4.3 V
1/5kHz/C1 < 70 Ohm
C1 > 1 uF

For higher loads a more negative voltage and a feedback circuit could be used.
2 separate circuits for OpAmps and for user should be used.
